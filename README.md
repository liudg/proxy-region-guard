# 代理地区卫士 (Proxy Region Guard)

Windows 桌面端代理出口地区实时防漂移监控、进程安全熔断、系统时区/区域一键同步，以及 **Claude / Antigravity 跨订阅专属节点独立代理启动器**。

## 核心特性

1. **三通道相互解耦架构**
   - **Antigravity 启动器专栏（纯代理指定）**：支持从任意已激活或未激活的 Clash Verge Rev 订阅组中挑选指定节点，动态在 Mihomo 内核注入专属本地端口（默认 `127.0.0.1:27898`）与 `PROCESS-NAME` 规则（覆盖 `Antigravity.exe` 及 `language_server_windows_x64.exe`），并通过命令行 `--proxy-server` 与环境变量绑定代理；启动前终止旧实例并确认关联进程全部退出，运行期间不执行地区限制。
   - **Claude 专栏（三重强校验 + 会话出口 IP 锁定 + 唯一安全启动入口）**：独立绑定专属本地端口（默认 `127.0.0.1:27897`），强制校验 `[Claude 选定节点真实出口地区] == [Windows 系统区域] == [Windows 系统时区]` 及 Claude 服务识别地区与分流出口归属地一致性；默认开启**会话出口 IP 锁定**（锁定会话启动时 `claude.ai/cdn-cgi/trace` 识别的真实出口 IP，运行期发生任何 IP 漂移、同国换 IP 或 IPv4/IPv6 双栈切换均立即 0 秒强杀进程树，支持动态住宅代理用户按需开关）；支持拦截外部未授权直接启动的 Claude Desktop，运行期检测到安全条件失效时终止全部关联进程树（含 `cowork-svc.exe` 等后台服务）。切换节点或专属端口前确认关联进程全部退出，完成检测后需要重新启动 Claude。
   - 选择节点时严格使用指定订阅；订阅或节点缺失时提示重新选择。内核配置更新保留用户自己的进程路由规则。
   - **实时监控与进程守护专栏**：监控系统代理或主代理通道的实时落地出口，偏离默认保护地区或断连时自动终止自定义受保护进程列表。

2. **真实落地出口穿透检测 + 目标服务地区真伪与会话 IP 核验**
   - 经由对应代理隧道依次请求回显端点（Cloudflare Connectivity Trace / AWS CheckIP 等），获取出口公网 IP。
   - 内置 `GeoLite2-Country` 离线 `.mmdb` 数据库（支持 IPv4 与 IPv6），毫秒级纯本地解析国家/地区代码与中文名。
   - Claude 每次均实时请求 `https://claude.ai/cdn-cgi/trace`（禁用结果缓存，并内置独立最高 10 秒运行期巡检定时器，不受全局心跳关闭或长间隔影响），同时校验常规出口离线库归属地、`claude.ai` 看到的实际出口 IP 离线库归属地及 `claude.ai` 边缘识别国家三者同国（兼容同国 AI 链式解锁分流，拦截跨国分流）；请求失败或结果缺失时阻止启动。Antigravity 通过 YouTube 和 Google 页面检查 Google 识别地区（允许复用 45 秒内结果）。
   - Claude 运行期间，请求超时、HTTP 错误或地区解析失败会进入静默后台复核，每隔 5 秒尝试检测，同一时间最多执行一次检测。首次失败后持续 30 秒仍未恢复时终止 Claude 并弹窗；计时独立于网络请求。若复核恢复时出口 IP 未变则静默恢复；若恢复后出口 IP 已发生漂移则立即 0 秒强杀并弹窗。
   - 明确的会话出口 IP 漂移、地区冲突、系统时区/区域不匹配或专属代理绑定失效会立即 0 秒终止 Claude 并置顶弹窗（出口 IP 漂移弹窗直观对比“会话锁定 IP → 当前漂移 IP”）。终止提醒始终显示完整原因和进程处理结果；主面板显示锁定会话 IP、复核期限及最后成功时间。
   - 控制接口请求失败时，专属绑定标记为尚未确认并进入静默复核。同一节点、订阅和端口保留最后成功校验的地区，供复核期间检查系统时区和区域；切换绑定时清除该记录。

3. **Windows 系统时区与区域一键同步 & 安全还原**
   - 内置常用国家/地区到 Windows 标准时区 ID 的映射表，针对美、加、澳、俄、巴等多时区国家通过出口 IP 查询城市级 IANA 时区；映射缺失时拒绝同步和时区匹配。
   - 支持一键将 Windows 系统时区与系统国家/地区（GeoID / Locale）同步至目标代理地区，或一键安全还原为中国默认时区（`China Standard Time` / `CN`），切换前自动检测并清理冲突进程以防暴露。

4. **双擎变更捕获与置顶强提醒**
   - **本地事件实时驱动 + 轻量心跳兜底**：自动连接本机 Clash 系列客户端（同時支持 Windows Named Pipe 与本地 HTTP 控制端口），监听订阅重载、节点切换、系统代理注册表与虚拟网卡变动。
   - **系统托盘状态变色 + 独立置顶警告弹窗**：屏幕右下角 `screen-saver` 级置顶弹窗，不抢占当前输入焦点，支持快捷处置。

## 启动与打包命令

### 方式一：双击快捷启动（日常使用推荐）
直接双击项目根目录下的 **[`启动应用.bat`](./启动应用.bat)** 即可启动桌面程序。

### 方式二：命令行启动与打包
```powershell
# 构建并启动正式桌面窗口
npm start

# 开发调试模式（支持前端热更新）
npm run dev

# 仅编译前后端生产代码
npm run build

# 运行 Windows 回归检查
npm test

# 打包 Windows x64 绿色免安装发行版（输出至 release/代理地区卫士-win32-x64）
npm run package
```

回归检查使用临时配置目录、真实子进程和真实网络连接，验证配置保存失败、进程退出确认、状态判定、DNS 解析和图标生成。时区前置检查要求 Claude 已关闭；系统区域同步成功路径仅在当前区域与默认时区一致时执行。

内核集成检查使用独立端口和临时配置启动 Mihomo，读取本地订阅节点，验证 provider 更新后的自动检测、并发绑定、旧探测任务取消、保存失败时的绑定状态和数字密码认证。默认依次查找环境变量 `GUARD_TEST_MIHOMO` 及本机 Clash Verge / Service 内核路径。测试结束后关闭该独立内核并清理临时文件。

Claude 运行期判定检查可通过 `GUARD_TEST_CLAUDE_PROXY` 指定真实代理地址，默认读取系统代理或本机 Clash 混合端口。检查使用真实控制接口认证失败和代理出口请求，系统区域冲突通过输入不同地区及时区数据验证，不修改 Windows 设置。
