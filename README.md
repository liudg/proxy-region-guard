# 代理地区卫士 (Proxy Region Guard)

Windows 桌面端代理 IP 地区变更实时监控与强提醒工具。

## 核心特性

1. **真实落地出口穿透检测（完美解决“中转入口 ≠ 落地出口”）**
   - 自动经由本地代理隧道请求全球基础设施纯文本回显端点（Cloudflare Connectivity Trace / AWS CheckIP 互备），100% 获取远端真实落地出口公网 IP。
2. **100% 离线 GeoIP 地区解析（零第三方查 IP 接口限流）**
   - 内置 `GeoLite2-Country` 离线 `.mmdb` 数据库（支持 IPv4 与 IPv6），毫秒级纯本地解析国家/地区代码与中文名。
   - 辅助识别“广播 IP / 路由接入点偏差”（当 IP 注册归属地与边缘接入位置不同时自动标注）。
3. **双擎变更捕获（毫秒级事件监听 + 轻量心跳兜底）**
   - **本地事件实时驱动**：自动连接本机 Clash 系列客户端（Clash Verge Rev / Mihomo Party / CFW / FlClash / Clash Nyanpasu，同时支持 Windows Named Pipe 与本地 HTTP 控制端口），并监听 Windows 系统代理注册表与虚拟网卡变动。手动换节点、URL-Test 自动跳节点、关闭代理均可毫秒级感知。
   - **轻量心跳兜底**：可配置无感心跳（默认 15 秒），精准捕获“动态住宅代理不换节点但云端静默更换出口 IP”的场景。
4. **双重强提醒机制**
   - **系统托盘图标实时变色**：🟢 绿色（与默认地区一致）、🔴 红色（地区异常变更或连接断开）、🔵 蓝色（尚未设置默认地区）。
   - **软件自绘独立置顶警告弹窗**：屏幕右下角 `screen-saver` 级最高置顶弹窗（不受 Windows 勿扰模式屏蔽，且 `showInactive` 不抢夺当前打字焦点），支持一键“我知道了”或“将新地区设为默认”。

## 启动方式

### 方式一：双击快捷启动（日常使用推荐）
直接双击项目根目录下的 **[`启动应用.bat`](./启动应用.bat)** 即可无黑框启动桌面程序。

### 方式二：命令行启动
```powershell
# 构建并启动正式桌面窗口
npm start

# 开发调试模式（支持前端热更新）
npm run dev
```
